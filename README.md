# MERN Stack Training – Class Work

## 📌 About

This repository contains my **MERN Stack Training class work and practical exercises**.

The training focuses on learning full-stack web development using the MERN technology stack:

* **MongoDB** – Database
* **Express.js** – Backend framework
* **React.js** – Frontend library
* **Node.js** – JavaScript runtime
